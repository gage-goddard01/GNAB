# GNAB — Personal Budgeting Application

## Project Overview

GNAB is a Python-based personal budgeting application designed to help users organize their finances, create budget categories, and track spending.

The application is currently being developed as a command-line program, with future plans to provide a graphical interface.

## Technologies Used

Python

pandas

Git and GitHub

Visual Studio Code


## Current Features

Command-line menu interface

Default budget categories

Creation of custom budget categories

Budgeted and spent amount tracking using pandas DataFrames

Category balance calculations

User input validation for menu selections


## Installation and Usage

Install Python 3 and pandas.

Download or clone this repository.

Navigate to the GNAB project directory.

Run python3 GNABv1.py.
