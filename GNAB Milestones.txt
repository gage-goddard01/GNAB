Milestone 1: Working CLI Python budget tracker
Create functions that accept income and expenses, calculate totals, and present a budget summary in the terminal.
Proof of progress: You can successfully manage a basic monthly budget using a Python script.




Milestone 2: Persistent financial records
Use SQLite to store transactions, assign expense categories, and retrieve monthly information.
Proof of progress: You can close the application, reopen it, and retrieve your financial records.




Milestone 3: Working applicaation GUI
Use Flask to build a browser interface for adding transactions, viewing balances, and tracking spending.
Proof of progress: You have a functional personal budgeting application running locally.




Milestone 4: Public portfolio demonstration
Deploy a separate instance using fictional financial data. Add instructions, screenshots, a README, and a link from your portfolio website.
Proof of progress: An employer can open your website and explore the budgeting application without accessing your personal information.
